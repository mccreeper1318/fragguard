## What's New

FragGuard 26.3-1.2.2 introduces built-in tools for planning and safely performing database maintenance while preserving rollback history.

- **Database Maintenance menu:** Schedule maintenance, review progress and inspect compaction status in game.
- **Player warnings:** A yellow countdown Boss Bar and chat reminders warn players before maintenance. Staff can use a separate bypass.
- **Database diagnostics:** Check storage, SQLite page reuse, retention counts, database health and deep-history integrity.
- **Safer compaction:** Create and fully verify a separate SQLite compacted copy, with capacity checks and explicit confirmation before replacing anything.
- **Recovery protections:** Persistent maintenance stages, verified backup/sidecar checks and startup safeguards prevent unapproved replacements.
- **Optional space management:** Read-only storage recommendations and incremental reclamation for databases with compatible SQLite settings.

### Important before using database maintenance

Maintenance **does not** compact or replace your database automatically. Existing SQLite databases are not converted to incremental auto-vacuum. A full compaction creates a **separate candidate** using `VACUUM INTO` and requires verification, approval, a clean shutdown, and a manual file-manager replacement. Server owners should keep a coherent original database backup together with any matching WAL/SHM files.

**STRICT** mode rejects replacing the database if its history or rollback/undo data changed after the copied snapshot. **Snapshot** mode requires explicit consent and may discard FragGuard history, rollback and undo changes made after the actual SQLite snapshot. **Minecraft world changes are never rolled back** by a database replacement. Insufficient disk/quota space or missing/altered files can block maintenance.
